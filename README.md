# AI-Productivity-Assistant
An AI-powered assistant built for the OnSite program that automates workplace tasks to boost productivity.

## 📌 Project Overview
This project focuses on designing and developing an AI assistant that helps automate common workplace tasks using tools like ChatGPT, Gemini, and Notion AI.

The assistant covers:
- **Email generation**
- **Meeting summarization**
- **Task planning**
- **Research assistance**
- **Chatbot interaction**

## 🎯 Key Expectations
- Apply AI tools effectively for real workplace problems
- Demonstrate strong prompt engineering skills
- Document progress and learnings throughout the project

## 🛠️ Tech Stack
- AI Tools: ChatGPT, Gemini, Notion AI
- Language: Markdown, Python
- Platform: GitHub

## 🚀 How to Use
1. Browse each folder for prompts and outputs
2. See examples of AI-generated emails, summaries, and task plans
